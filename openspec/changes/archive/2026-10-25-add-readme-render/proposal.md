## Why

The README describes the SKQYACE010 model only in text and tables, so a visitor can't see what the switch looks like without installing KiCad or a STEP viewer. A rendered picture at the top of the README shows the shape and the four part colours at a glance. If the picture is generated by the build from the same coloured solids as the STEP, it can't drift out of date when the model changes.

## What Changes

- `uv run build-model` also writes a coloured raster image, `models/SKQYACE010.png`: one isometric view of the whole switch with each part in its STEP colour (base black, cover stainless grey, stem brown, terminals gold), shaded so the cover tier, stem and terminals read as 3D.
- The image is rendered headless in pure Python inside the existing uv environment. It needs no display, GPU, KiCad or other external tool, so it works on every platform the environment supports.
- The image follows the same build rules as the STEP and STL: it is written to a temporary directory, checked (right size, not blank), and moved into `models/` only if every check passes. A failed build leaves the committed image unchanged.
- The image is byte-identical between runs on the same platform and lockfile, like the other outputs.
- The README shows the image near the top and lists `models/SKQYACE010.png` in its file table.
- `matplotlib` is declared as a direct dependency. It is already pinned in `uv.lock` as a transitive dependency, so the locked version doesn't change.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `model-export`: the build command also produces the README image. A new requirement defines the image (view, colours, size, headless rendering), and the existing "single command", "failed build" and "reproducible output" rules are extended to cover it.
- `skqyace010-model`: the "Provenance and licence documentation" requirement adds that the README shows the generated render.

## Impact

- **Code:** `src/skqyace010/build.py` (export now produces three files and `main` prints three paths), a new render module under `src/skqyace010/`, `src/skqyace010/checks.py` (image check), and `tests/test_outputs.py` (fixture and assertions for the third output).
- **Outputs:** new committed file `models/SKQYACE010.png`. The STEP and STL are unchanged.
- **Docs:** `README.md` (embedded image, file table row, build description).
- **Dependencies:** `pyproject.toml` gains `matplotlib`. Its version in `uv.lock` stays 3.11.2; it was already pulled in through `vtk`.
- **Build time:** a few extra seconds to tessellate and rasterise.
