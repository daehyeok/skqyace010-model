## MODIFIED Requirements

### Requirement: Provenance and licence documentation

The repository SHALL include a README that states the model's provenance (drawn from the datasheet, no vendor geometry used), its licence and the KiCad usage transform. The README SHALL also give the dimension table, showing which values come from the datasheet and which are estimates. It SHALL state that colours and appearance follow product photos, which are not part of the repository, while every dimension comes from the datasheet. The README SHALL show the generated preview image `models/SKQYACE010.png` near the top, before the provenance section, with alternative text that names the part, and SHALL list that file in its table of output files. The README SHALL NOT embed product photos or any image that was not generated by the build.

#### Scenario: Consumer can verify licence cleanliness

- **WHEN** a downstream user reads the README
- **THEN** they find the source document, a statement that no vendor 3D data was used, a statement that product photos informed colour and appearance only and are not included, the licence, and the footprint transform `(0,0,0)/(1,1,1)/(0,0,0)`

#### Scenario: README shows the model render

- **WHEN** the README is rendered, for example on the repository web page
- **THEN** the generated `models/SKQYACE010.png` is displayed above the provenance section through a relative link that resolves to a committed file, with alt text naming the SKQYACE010

#### Scenario: Only generated images are embedded

- **WHEN** every image reference in the README is listed
- **THEN** each one points to a file that `uv run build-model` produces
